## Що в репозиторії

Один файл `lab4_dp_greedy.py` із двома частинами:

| Частина | Задача | Підхід | Що робить код |
|---|---|---|---|
| I, задача 2 | Кенгуру: скільки маршрутів через річку з n купин (2 ≤ n ≤ 30), стрибок на 1 або на 2 | динамічне програмування | `a[i] = a[i-1] + a[i-2]`, `a[0] = a[1] = 1`; три реалізації (пряма рекурсія, рекурсія з пам'яттю, цикл по таблиці), перебір усіх маршрутів для перевірки, лічильник викликів |
| II, задача 2 | Пісок: заповнити рюкзак на n кг купами піску так, щоб вартість була найбільшою (пісок ділиться) | жадібний алгоритм | сортування за ціною за кг, перевірка проти точного розв'язку (лінійна програма) на 1000 випадкових задач, контрприклад для неподільних предметів (рюкзак 0/1 динамічним програмуванням) |

## Запуск

```
pip install -r requirements.txt
python lab4_dp_greedy.py kenguru    # частина I
python lab4_dp_greedy.py pisok      # частина II
python lab4_dp_greedy.py            # обидві частини
```

Потрібен Python 3.8 або новіший. Бібліотека `scipy` використовується лише для
перевірки жадібного алгоритму лінійною програмою. Повний запуск частини II
триває кілька секунд, бо виконується 1000 перевірок.

## Ключові результати запуску

- Кенгуру, n = 3: 5 маршрутів; n = 30: 2 178 309 маршрутів (на протилежний
  берег). Пряма рекурсія робить 4 356 617 викликів, з пам'яттю 61.
- Пісок, рюкзак 50 кг, купи (20 кг по 5), (30 кг по 9), (40 кг по 7): 410 грн.
  Жадібний збігається з точним розв'язком у 1000 з 1000 випадкових задач.
- Ті самі предмети (10 кг за 60, 20 кг за 100, 30 кг за 120) у рюкзаку на
  50 кг: жадібний для цілих предметів 160, динамічне програмування 220,
  жадібний для предметів, що діляться, 240.
